\section*{Highlights}
\begin{itemize}
\item Patient-blocked calibration bounds alarms per patient-day, not per hour.
\item Source thresholds lose sensitivity across hospitals despite lower alarm rates.
\item About 10\% target labels recover the 1-per-day threshold in this cohort.
\item LightGBM improves cross-site sensitivity but does not remove the shift.
\item A finite-grid empirical-Bernstein bound certifies each operating point.
\end{itemize}
